# 🐚 0-Shell — Minimalist Unix Shell in Rust

## 📌 Overview
0-Shell is a lightweight Unix-like shell built entirely in Rust, without relying on external binaries.  
The goal of this project was to understand how a shell works internally by implementing core functionalities from scratch.

---

## ⚙️ Features

### 🧩 Built-in Commands
- `cd`
- `ls`
- `pwd`
- `cat`
- `cp`
- `rm`
- `mv`
- `mkdir`
- `echo`
- `exit`

---

## 🛠️ Core Capabilities
- Process execution  
- File system operations  
- Command parsing  
- Error handling  
- Graceful termination with `Ctrl + D`  

---

## 🧠 What I Learned
This project provided a deep understanding of:
- Unix system calls  
- Process management  
- Shell architecture and behavior  

Building a tool used daily at such a low level offers a new perspective on how systems operate behind the command line.
